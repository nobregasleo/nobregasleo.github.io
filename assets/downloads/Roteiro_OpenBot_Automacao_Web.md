# ⚡ Roteiro OpenBot: Automação no Navegador
**Por Leonardo Nóbrega**

Este roteiro explica como configurar um agente gratuito para automatizar navegação e cliques na web direto no seu computador.

---

## 1. O que é o OpenBot?
O OpenBot é uma ferramenta open-source que roda localmente no seu computador, permitindo que agentes de IA controlem o navegador Chromium, cliquem em botões, preencham campos e façam tarefas repetitivas onde não existe API oficial.

---

## 2. Passo a Passo de Execução
1. **Defina o Escopo:** Nunca peça para o agente fazer tudo de uma vez. Defina a URL exata de entrada e os seletores dos botões.
2. **Separe as Credenciais:** Nunca deixe senhas dentro dos prompts; use variáveis de ambiente locais.
3. **Validação Humana (Human-in-the-Loop):** Para ações com risco financeiro ou publicação em redes sociais, coloque sempre uma pausa aguardando o seu OK antes do clique final.
